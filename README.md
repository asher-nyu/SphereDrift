### SphereDrift: Interactive OpenGL 3D Graphics Simulation Featuring Dynamic Object Movement, Shadow Rendering, Texture Mapping, Fog Effects, and Animated Fireworks Using Modern GLSL Shaders
**Jan 2025 – May 2025**

- Developed a full-featured 3D graphics application in C++ using OpenGL, GLUT, and GLSL, implementing real-time shading, fog rendering, and user-interactive camera and object controls
- Engineered a modular object-oriented system to load custom geometry files, compute surface normals (flat/smooth), and render dynamic lighting and shadows using programmable shader pipelines
- Designed and animated a physics-inspired rolling sphere system with continuous pathing, realistic rotation logic, and texture-mapped effects (checkerboard, contour lines, lattice)
- Created a particle-based fireworks engine with randomized color/velocity vectors and time-based rendering using custom vertex/fragment shaders and GPU buffer management
